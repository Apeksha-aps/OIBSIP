# Python BMI Calculator (OIBSIP - Task 2)

A command-line Body Mass Index (BMI) Calculator created by **Apeksha Suhas Phapale** as part of the Oasis Infobyte Internship Program.

## Features
- Accepts user weight (in kilograms) and height (in meters)
- Validates inputs to prevent zero, negative, or non-numeric errors
- Calculates BMI accurately to two decimal places
- Classifies results into standard health categories along with a personalized wellness note

## How to Run
```bash
python bmi_calculator.py
