# Python Random Password Generator (OIBSIP - Task 3)

A customizable command-line password generator created by **Apeksha Suhas Phapale** as part of the Oasis Infobyte Internship Program.

## Features
- Enforces a minimum password length of 8 characters
- Allows users to customize character sets (uppercase, lowercase, numbers, symbols)
- Requires at least two character types for stronger security
- Validates all user inputs and supports generating multiple passwords in one session

## How to Run
```bash
python password_generator.py
