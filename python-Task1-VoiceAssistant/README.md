# Python Voice Assistant (OIBSIP - Task 1)

A beginner-friendly Python Voice Assistant created by **Apeksha Suhas Phapale** as part of the Oasis Infobyte Internship Program.

## Features
- Listens to voice commands via microphone (`SpeechRecognition`)
- Responds with natural speech output (`pyttsx3`)
- Greets the user on saying "Hello"
- Tells the current time and date
- Searches queries directly on Google via web browser
- Handles unrecognized speech gracefully

## How to Run
1. Install dependencies:
   ```bash
   pip install SpeechRecognition pyttsx3 pyaudio
   ```
2. Run the script:
   ```bash
   python voice_assistant.py
   ```
